Mi página web

Descripción

Esta página web fue creada utilizando HTML, CSS y JavaScript. Incluye contenido de ejemplo, listas, una tabla, elementos multimedia, formularios y una página de contacto independiente.

Características

- Menú de navegación.
- Elementos de texto.
- Listas ordenadas y desordenadas.
- Tabla de tecnologías.
- Sección multimedia.
- Formulario con nombre, correo y país.
- Barra lateral con contenido desplegable.
- Botón para cambiar el tema.
- Página de contacto independiente.
- Formulario de contacto.
- Botón para volver al inicio.
- Diseño adaptable a celulares.

Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

Estructura del proyecto

- "index.html": página principal.
- "contacto.html": página de contacto.
- "css/estilo.css": colores y diseño.
- "js/script.js": funciones de la página principal.
- "js/contacto.js": función del formulario de contacto.
- "README.md": información del proyecto.
